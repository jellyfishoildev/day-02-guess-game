# Number Guessing Game

เกมทายเลข 1-100 ผ่านเทอร์มินัล เขียนด้วย Python

## Features

- สุ่มเลขลับ 1-100 ทุกครั้งที่เริ่มเกม
- บอกใบ้ "มากไป" / "น้อยไป"
- นับจำนวนครั้งที่ทาย
- ดักข้อผิดพลาด: พิมพ์ไม่ใช่ตัวเลข หรือเลขนอกช่วง 1-100
- กด Ctrl+C เพื่อออกจากเกมได้

## วิธีรัน

```bash
git clone https://github.com/jellyfishoildev/day-02-guess-game.git
cd day-02-guess-game
python guess_game.py
```

## ตัวอย่างการเล่น

```
ทายเลข 1-100: 50
น้อยไป!
ทายเลข 1-100: 75
มากไป!
ทายเลข 1-100: 63
ถูกต้อง! ทายทั้งหมด 3 ครั้ง
```

## สิ่งที่ได้เรียนรู้

- สุ่มเลขด้วยโมดูล `random`
- วนลูปด้วย `while True` และออกด้วย `break`
- ข้ามรอบด้วย `continue` เมื่ออินพุตไม่ถูกต้อง
- จัดการ error ด้วย `try/except`
