# Day 2: Number Guessing Game (เกมทายตัวเลข)

โปรแกรมสุ่มเลข 1-100 ให้ผู้เล่นทาย โดยบอกว่า "มากไป" หรือ "น้อยไป" จนกว่าจะทายถูก พร้อมบอกจำนวนครั้งที่ทาย

## วิธีการรันโปรแกรม

```bash
python guess_game.py
```

## ตัวอย่างการเล่น

```text
ทายเลข 1-100: 50
น้อยไป!
ทายเลข 1-100: 75
มากไป!
ทายเลข 1-100: 63
ถูกต้อง! ทายทั้งหมด 3 ครั้ง
```
